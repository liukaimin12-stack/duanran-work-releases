# 端然work · 公开测试安装包

此仓库用于发布端然work的公开测试安装包、版本说明和校验文件。任何人都可以下载安装测试版；源码保存在独立的私有仓库中。

## 下载

当前尚未发布安装包。发布后，请从 [Releases](https://github.com/liukaimin12-stack/duanran-work-releases/releases) 下载对应版本，并核对随包提供的 SHA-256 校验文件。

是否支持应用内在线更新，以各版本的发布说明为准。本仓库的创建不代表在线更新已经启用。

## 使用提示

- 测试版可能存在问题，升级前请备份重要资料。
- 模型或图片服务的 API 密钥由使用者自行在应用内配置，安装包不包含可供公众使用的服务密钥。
- 请勿将个人密钥、账号凭据或用户资料提交到此仓库、公开问题或评论中。
- 本地密码锁仅保护相应电脑上的使用，不限制谁可以下载安装。
