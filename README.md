# 端然work · 公开测试安装包

此仓库提供端然work的公开测试安装包、版本说明和校验文件。任何人均可下载安装；应用源码保存在独立的私有仓库。

## 下载与安装

请从 [Releases](https://github.com/liukaimin12-stack/duanran-work-releases/releases) 下载完整 Windows x64 安装器，并核对随包的 SHA-256。无需下载或自行组合仓库中的传输分块。

0.6.1 是过渡测试版。从旧版本升级时，请先备份重要资料、处理未保存内容和在途任务，正常关闭应用后手动覆盖安装一次。应用保留原安装身份和工作资料路径。旧客户端不能通过原签名更新通道自动迁移到本版。

## 更新通道

0.6.1 使用独立的测试更新清单，从固定 GitHub 发行仓库经 HTTPS 获取更新，并校验仓库、平台、版本、文件大小和 SHA-256。此通道没有独立发布者签名，保护弱于签名通道，仅用于公开测试。文件完整性校验不能代替发布者身份签名。

0.6.0 及更早发行版本的原有签名附件保持不变。实际可更新版本以 Releases 和客户端检查结果为准。

## 使用提示

- 测试版可能存在问题，请勿将其作为重要资料的唯一保存位置。
- 模型或图片服务的 API Key 由使用者自行配置，安装包不提供公众共用的服务密钥。
- 请勿在此仓库、公开问题或评论中提交个人密钥、账号凭据或工作资料。
- 本地密码锁仅保护相应电脑上的使用，不限制安装资格。
