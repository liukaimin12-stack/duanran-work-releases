# 端然work · 公开测试安装包

此仓库用于端然work公开测试安装包、版本说明和校验文件。任何人都可以下载安装测试版；源码保存在独立的私有仓库。

## 下载

请从 [Releases](https://github.com/liukaimin12-stack/duanran-work-releases/releases) 下载安装器并核对随包的 SHA-256。若 Releases 为空，表示安装包尚未发行。

本次验收先手动安装带发布者公钥的 0.5.2，再通过应用内更新到 0.5.3。0.5.4 修正固定 GitHub 更新源与系统代理、PAC、Fake-IP 网络环境的连接方式，0.5.5 进一步修正中文应用名称进入默认请求标识后导致下载 CDN 返回 HTTP 400 的问题；旧版若在获取清单前受阻，需手动安装修正版后继续验证。此前没有内置更新信任的 0.5.0/0.5.1 无法通过修改运行时设置接入。实际可更新版本以 Releases 和客户端检查结果为准。

## 使用提示

- 测试版可能存在问题，请先备份重要资料；安装更新前处理未保存内容和在途任务。
- 模型或图片服务的 API Key 由使用者在应用内自行配置，安装包不包含可供公众使用的服务密钥。
- 请勿在此仓库、公开问题或评论中提交个人密钥、账号凭据或用户资料。
- 本地密码锁仅保护相应电脑上的使用，不限制安装资格。

## 本次发布传输

为完成限 0.5.2、0.5.3、0.5.4、0.5.5、0.6.0 的获准云端更新测试，安装器以小块暂存在本仓库，由本仓库自己的 GitHub Actions 验证签名、分块/整包摘要后拼回完整安装器并发布三个附件。用户直接下载 Releases 里的完整安装器，无需处理分块。

此桥不保存签名私钥、模型密钥、PAT 或跨仓库凭据；只使用 GitHub 为本次发布工作提供的短期、限本仓库令牌。发布脚本拒绝其他版本及覆盖不同的既有附件。这些测试版二进制占用数百 MB Git 历史，这是本次测试的传输办法，不是长期大规模分发方案。
